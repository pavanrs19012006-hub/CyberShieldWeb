# CyberShield – Smart Cyber Threat Detection and URL Security Analyzer

## Project Description
CyberShield is a Java-based web application designed to analyze URLs and identify potentially suspicious or unsafe links. It provides user registration, login, URL scanning, scan history, and security reports.

## Technologies Used
- Java
- Java Servlets
- JSP
- JDBC
- Hibernate ORM
- JSTL and Expression Language (EL)
- HTML and CSS
- MySQL / MariaDB
- Apache Tomcat 8.5
- NetBeans IDE
- XAMPP

## Main Features
1. User Registration and Login
2. Secure Password Hashing
3. URL Security Scanning
4. Threat Classification
5. Scan History
6. Security Reports
7. Report Update and Delete
8. Session Management
9. Error Handling

## Database Setup
1. Install and start MySQL/MariaDB using XAMPP.
2. Create a database named `cybershield_db`.
3. Import the schema-only SQL file provided with the project.
4. Configure the database connection in `hibernate.cfg.xml`.
5. Ensure the required database tables are created.

## How to Run
1. Install JDK 8 or a compatible JDK.
2. Install Apache Tomcat 8.5.
3. Open NetBeans IDE.
4. Open the `CyberShieldWeb` project.
5. Check the required project libraries.
6. Start MySQL/MariaDB from XAMPP.
7. Run the project using Apache Tomcat.
8. Open the application in your browser.
